## 1. 正式価格

| 商品 | 価格 |
|---|---|
| **店舗ホームページ制作** | **50,000円〜（税別）** |
| **ホームページ管理・保守** | **月額 5,000円〜（税別）** |

- **すべて税別**。表示するときは必ず「（税別）」を付ける
- **必ず「〜」を付ける**（下限であり、内容により見積もる）
- **「50,000円ですべて対応する」とは表示しない**

## 2. 制作の基本範囲（50,000円〜に含む）

- 既存テンプレートを活用した制作
- スマートフォン対応
- **最大5ページ相当**
- 店舗紹介
- メニュー・料金
- スタッフ紹介
- アクセス・営業時間
- LINE公式アカウントへの導線
- Instagramへの導線
- 外部予約サービスへの導線
- 問い合わせ導線
- 基本SEO設定
- 公開作業
- **修正2回まで**

### ★「最大5ページ相当」の定義

実装方式が**複数HTMLでも、1ページ内のセクション構成でも構わない**。
**掲載する情報量の上限を説明するための販売上の基準**であり、ファイル数の約束ではない。

## 6. 個別見積もりの条件・実費の扱い

| # | 原則 |
|---|---|
| 1 | **制作内容を確認したうえで正式見積もりを出す**（金額を先に確定しない） |
| 2 | ドメイン・サーバー・外部サービスの**実費は必要に応じて別途**とする |
| 3 | **素材（写真・文章）提供の有無で納期と価格が変わる** |
| 4 | ページ数・外部連携の有無で変わる |
| 5 | 「サーバー・ドメイン実費込み」と**断定しない** |

## 7. Salon との関係

| # | 原則 |
|---|---|
| 1 | **Salon契約を強制しない** |
| 2 | **HP単独でも受注できる** |
| 3 | Salonとの同時導入は**自然に提案する**（押し付けない） |
| 4 | 「HP制作がSalon月額に含まれる」と**言わない・書かない**（Salon営業SSOT §12・§18） |
| 5 | Salonの「店舗ページ制作・管理」は Smart Labo Salon 上の公開ページであり、**本書のホームページ制作とは別商品** |

### 販売導線

```text
HPで新規顧客との入口を作る
  → 予約・LINE・問い合わせ導線を整える
```

## 9. 誤認防止（表示してはいけないこと）

| × 表示しない | 理由 |
|---|---|
| 独自予約システムが基本料金に含まれる | 別料金（§4） |
| 写真撮影が基本料金に含まれる | 別料金 |
| ロゴ制作が基本料金に含まれる | 別料金 |
| 無制限に修正できる | 基本は**修正2回まで** |
| 高度なSEOの成果を保証 | 成果保証をしない |
| 必ず5万円で完成する | 下限価格であり、内容により見積もる |
| サーバー・ドメイン実費込み | 実費は必要に応じて別途 |
| 「HP制作」がSalonに含まれる | 別商品（§7-4） |
| 実績数・効果数値・お客様の声（未取得のもの） | 捏造しない |

## 10. 内部見積もり時の注意

1. **素材の有無**（写真・文章・ロゴ）を最初に確認する — 納期と価格の主要因
2. **ページ数**が5相当を超えるかを確認する
3. **外部サービス連携**（予約・EC・多言語）の有無を確認する
4. 公開後の運用（更新頻度）を確認し、**管理・保守の要否**を提案する
5. Salonを同時提案する場合も、**HP単独でも受注できる**ことを明示する
6. 見積書には**税別表記**と**実費の扱い**を必ず書く

## 11. 変更手順

- 価格・範囲を変更する場合は、**本書のVERSIONを上げる**か正式改定する
- 公開ページ（Web）の表記は本書を参照して更新する
- Works価格の整合チェック（`docs/reviews/tools/check-prices.js`）は
  **Works向けの仕組み**であり、本書の価格は対象外。Webへ掲載する段階で
  同等のチェックを追加するかを Phase 5 で判断する
