### ★「最大5ページ相当」の定義

実装方式が**複数HTMLでも、1ページ内のセクション構成でも構わない**。
**掲載する情報量の上限を説明するための販売上の基準**であり、ファイル数の約束ではない。

### ★「標準問い合わせフォーム」の範囲（VERSION 2）

標準料金に含むのは、次の**5項目だけ**を持つ単純なフォームである。

| # | 項目 |
|---|---|
| 1 | 名前 |
| 2 | メールアドレス **または** 電話番号（どちらか一方を必須） |
| 3 | 問い合わせ種別 |
| 4 | 問い合わせ内容 |
| 5 | プライバシーポリシー同意 |

標準で備える安全要件：CSRF対策・honeypot・rate limit・入力validation・
HTMLエスケープ・送信先の店舗別分離・ログへ本文や個人情報を不用意に出さないこと・
送信完了／失敗の表示・プライバシーポリシーへのリンクと同意。

**含まない**：ファイル添付、予約確定、決済、複雑な条件分岐、多数の独自項目、
外部システム連携（いずれも §4 の別料金）。

### ★「基本プライバシーポリシー」の範囲（VERSION 2）

- 基本テンプレートを使用する
- 店舗ごとに取得情報・利用目的・問い合わせ窓口等を確認する
- Smart Labo が**人の目で最終確認**する
- **完全な個別法務文書の作成、および専門家によるレビューは標準範囲外**（§4）
- **法的完全性を保証する表現は使わない**（§9）

### ★「確認用URL」の範囲（VERSION 2）

- 修正2回の確認に使用する制作工程の一部として、標準料金に含む
- 正式URLとは分離する／推測困難なURLを使う／`noindex` を設定する／
  robots でクロール対象外にする／確認期限を設ける／
  最終承認後に削除または停止する
- 秘密情報・非公開の個人情報は掲載しない
- **検索非掲載（noindex・robots除外）はアクセス制限や認証を意味しない**（§9）

## 12. 請求・決済ルール（VERSION 3）

> ★本節は**請求の方法**を定める。**価格そのものは §1〜§5 が定める。**
> 本節の追加によって価格数値・ページ数・修正回数・保守料金は変更していない。

### 12-1. HP基本制作費

| # | 規定 |
|---|---|
| 1 | 標準価格は **50,000円〜（税別）** を維持する（§1） |
| 2 | 標準50,000円（税別）の場合、**請求額は税込 55,000円**（消費税10%） |
| 3 | **着手金と残金には分割しない。**「着手金50%・残金50%」方式は採用しない |
| 4 | 契約成立後、**制作開始前に Stripe の請求書で一括請求する** |
| 5 | **入金確認後に制作を開始する** |
| 6 | **Stripe のカード決済画面で顧客自身がカード情報を入力する** |
| 7 | **Smart Labo はカード番号・有効期限・セキュリティコード等を受領・保存しない** |

### 12-2. 契約時点で追加内容が確定している場合

基本制作費と追加費用を**同じ見積書・契約内容へ記載**し、
**合計額を Stripe の請求書で制作開始前に一括請求する。**

計算例（★あくまで計算の書き方の例である）

```text
HP基本制作費       50,000円
追加ページ等       20,000円
─────────────────────────
小計               70,000円
消費税（10%）       7,000円
─────────────────────────
請求額             77,000円（税込）
```

> ★**上記の例を固定価格や標準追加料金として扱わない。**
> 「追加ページは20,000円」という標準料金は存在しない。
> **追加料金は案件ごとの見積りとする**（§4・§6）。

### 12-3. 制作開始後に追加作業が発生した場合

**次の順序を必須とする。順序を入れ替えない。**

| 順 | 手順 | 担当 |
|---|---|---|
| 1 | 追加希望を記録する | Smart Labo（案件管理） |
| 2 | **追加範囲・金額・納期への影響**を提示する | Smart Labo |
| 3 | **顧客から書面または記録可能な方法で承認を取得する** | 顧客 → Smart Labo |
| 4 | Stripe で追加分の請求書を発行する | Smart Labo |
| 5 | **所定の入金確認後**に追加作業または公開へ進む | Smart Labo |

**必ず守ること**

- **承認前に追加作業を開始しない。**
- **口頭だけの依頼を追加費用として請求しない。**
- 外注費・有料素材・有料サービス等の**実費が発生する作業は、原則として入金確認後に発注・着手する。**
- 追加請求が未払いの場合、**標準範囲の確認までは進めてよいが、
  追加部分を含む本番公開を行わない。**

### 12-4. 月額料金（制作費と混在させない）

| 商品 | 請求方法 |
|---|---|
| HP制作費・追加制作費 | **Stripe の一回限りの請求書** |
| HP保守・管理費（月額5,000円〜・税別） | **公開後に、別の Stripe サブスクリプション** |
| Smart Labo Salon 利用料 | **HPとは別商品・別の Stripe サブスクリプション** |

- 3つを**同一の請求へまとめない**。
- **HP単独契約が可能であること、Salon契約を強制しないことは維持する**（§7-1・§7-2）。
- 「HP制作がSalon月額に含まれる」とは言わない・書かない（§7-4）。

### 12-5. 管理責任の分離

| Stripe が持つもの | 案件管理（AI Sales 等）が持つもの |
|---|---|
| 請求書 | 見積り |
| 決済 | 契約内容 |
| 入金状態 | 追加作業の承認 |
| 未払い | 制作進捗 |
| 返金・取消 | 店舗確認 |
| 領収記録 | 公開承認 |
| 月額課金 | Stripe customer ID / invoice ID 等の参照情報 |

> ★**「すべてStripeで完結する」とは記載しない。**
> **お金の処理は Stripe、契約・制作管理は案件管理**という境界を守る。
> 案件管理側が保持してよいのは **参照ID（customer ID / invoice ID 等）** までであり、
> カード情報・決済手段の実体を持たない。
