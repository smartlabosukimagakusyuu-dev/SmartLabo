## 2. 最優先：AI整理セクション

### 原因の切り分け（重要）
1Dで代表へ提示した節別スクリーンショットは、**要素ごとに撮影する際に固定ヘッダーが節の途中へ合成される撮影上の副作用**を含んでいた（`sec-1440-07.png` で見出し「AIが整理する。」にヘッダーが重なって見えた）。実ページではヘッダーは常に画面最上部にのみあり、節の途中へ被らない。
→ 本工程では **撮影スクリプト側でヘッダーを除外**して再撮影し、あわせて節そのものの縦リズムも整理した。

### 修正内容
| 項目 | before | after |
|---|---|---|
| 見出しブロック | 左寄せ・lead 38em | **中央寄せ**（店舗ページ節と同じ型）・lead下余白 34px |

| 比較グリッド | 1fr / 44px / 1fr・gap18・矢印 padding-top 180px | **1fr / 36px / 1fr・gap14・矢印は縦中央**（align-items: stretch） |

| 比較UI本体・4ポイント | — | 左寄せ維持（text-align:left を明示） |
