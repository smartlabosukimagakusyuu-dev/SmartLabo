理由: `memo-phone` の氏名行は
「十和田 圭 様 ／ 覚えていることを短く。文章にしなくて大丈夫です。」という**1行**で、
氏名だけを切り落とすと**商品説明として最も効く一文まで失われる**ため。

**第二候補（代表が氏名も出したくない場合）**：
`memo-phone` を上端から約60px（2x換算）下でトリムし、`30秒メモ` 見出し＋氏名行を落として
「本日の施術」から下だけを使う。**ぼかし加工は第一候補にしない**（不自然になり、かえって疑念を生む）。
