## 1. 実装内容

### Section1 ヘッダー

- 左に正式ロゴのアイコンマーク＋「Smart Labo Works」、右にナビ6項目＋CTA「無料相談」。
- ナビ: サービス（`#solution`）/ 機能 / 料金 / 会社情報 / FAQ（`#faq`）/ お問い合わせ。
- `position: sticky` でスクロール後も固定。高さは **64px**（WEB-V2-1時点の72pxから縮小）。
- 背景は白の半透明＋`backdrop-filter`。境界線はスクロール時（`scrollY > 8`）にだけ出す。`backdrop-filter` 非対応環境では不透明の白へフォールバックする。
- **1080px以下でハンバーガーメニュー。** 日本語6項目＋CTAは860pxでは1行に収まらないため、v2の定義済みブレークポイントのうち1080pxを採用した（新しい段は増やしていない）。

### Section2 ヒーロー

- 左: アイブロウ「全社員に、AIという戦力を。」→ h1「会社を動かすAI。」→ 説明 → ボタン2つ（無料相談 / デモを見る）→ 安心バッジ3つ（AIは提案のみ / 確認して保存 / 中小企業向け）。
- 右: **Smart Labo Works の実画面キャプチャ**（詳細は次節）。ウィンドウ風のフレームに収め、奥行きは影だけで作っている。傾き・光沢・ネオンは使っていない。
- 背景は Smart Blue 7% の極薄のにじみ1枚のみ。グラデーションを主役にしていない。

### Section3 企業の悩み

- 「こんなお悩みありませんか？」＋カード6枚（顧客情報が分散 / 議事録が後回し / 社員によって品質が違う / タスクが漏れる / AI導入が進まない / 属人化）。
- 各カードにインラインSVGアイコン（stroke、`currentColor`）。外部アイコンフォント・CDNは使っていない。
- PC 3列 → 1080px以下 2列 → 640px以下 1列。

### Section4 Smart Labo Worksによる解決

- 「Smart Labo Worksが、日々の仕事を一つにつなぎます。」
- イラストではなく **情報の流れ** で見せる。左（顧客とのやり取り / 打ち合わせの会話 / 頼まれごと / 受け取った資料）→ 中央ハブ（Smart Labo Works）→ 右（整理された記録 / 次にやること / 文章の下書き / 探せる顧客情報）。
- 締めに **AI原則** を明示: 「AIは提案のみを行います。保存・更新・送信は、内容を人が確認してから操作します。」
- 860px以下では縦並びになり、矢印を90度回転させて流れを保つ。

### Section5 導入後の業務フロー

- 営業前 → 営業 → AI整理 → **確認** → 保存 → 次の業務 の6ステップ。
- **横スクロールにはしていない。** PC 6列 → 1080px以下 3列 → 640px以下 縦1列（番号を左、本文を右に置くレイアウトへ組み替え）。
- 「確認」だけを Smart Blue で強調し、人が必ず介在する工程であることを視覚的に示した。

### Section6 導入前と導入後

- 左「従来」（Light Gray・グレーの×）/ 右「Smart Labo Works」（白・Smart Blueの✓・影で前面化）。
- **数字は一切使っていない。** 削減率・削減時間・改善率の記載なし。
- 860px以下で縦積み。

### アニメーション

- フェード＋12pxの上方向スライドのみ。IntersectionObserver で1回だけ発火し、以後は監視解除。
- **スクロールジャックなし。** スクロール位置の乗っ取り・慣性の上書きは行っていない。
- `prefers-reduced-motion: reduce` では即時表示。
- JS無効時は `.js` クラスが付かないため、初期状態から全要素が表示される。
- さらに2秒後に強制表示するフォールバックを入れた（後述「発見した問題」参照）。

## 2. ヒーローの実画面キャプチャについて（要確認）

「モックではなく実際の画面キャプチャ」の指示に対し、**実在するプロダクトの画面を実際に起動して撮影**した。

| 項目 | 内容 |
|---|---|
| 撮影対象 | **Smart Labo Works ライト（汎用版）** — `C:\Users\user\Desktop\smartlabo-works-lite` |
| 画面 | 顧客・取引先（顧客一覧＋顧客詳細＋対応履歴＋次回予定） |
| 表示データ | **すべて架空**（同プロダクトの `server/db/seed.js` によるデモデータ。会社名は「あおぞら商事株式会社」等、住所は「サンプル市」、メールは `example.com`） |
| 撮影方法 | dist をローカルで配信し、APIは **AI無効**（`AI_ENABLED=false`）・**DBはscratchpadへコピーした使い捨て** で隔離起動。Puppeteerで1360×850（1x）と2720×1700（2x）を撮影 |
| 出力 | `website-v2/assets/images/app-customer.webp`（92KB）/ `app-customer@2x.webp`（230KB）。`srcset` で出し分け |
| 画面下の注記 | 「実際の画面です（表示しているデータはすべて架空のものです）」 |

**なぜライト（汎用版）を選んだか（代表のご確認をお願いします）**

もう一方の `C:\Users\user\Desktop\smartlabo-works` も起動して撮影したが、次の理由でトップページには採用しなかった。

1. **画面上部に「ミライエ様向けβ版」というバッジが常時表示される。** 実在する取引先名であり、公開サイトへ掲載すると取引関係の開示になる。代表の判断なしに載せられないと判断した。
2. 物件・査定など不動産業向けの画面構成で、トップページが扱う汎用の製品像と一致しない（不動産向けは専用ページの領域）。
3. 隔離DBが空のため、数値がすべて0の状態でしか撮影できなかった。

ライト（汎用版）は「業種を限定しない中小企業向け」「全社員に、AIという戦力を。」を掲げており、サイドバーの項目（ホーム / AIアシスタント / 顧客・取引先 / 記録・議事録 / 文章作成 / 社内マニュアル / タスク）がヒーローの説明文とそのまま対応する。

**留意点:** ライト（汎用版）は同リポジトリのREADMEで「UIプロトタイプ」と位置づけられている。実在する画面のキャプチャであることに変わりはないが、公開サイトへ掲載する画面として妥当かは代表のご判断を仰ぎたい。

**採用しなかった候補（差し替え可能）**: ホーム画面のキャプチャも取得したが、画面内に「今月削減（目安）5時間9分」という数値が表示されるため見送った。掲載禁止事項の「根拠のない削減時間」と受け取られる余地があるため、代表の明示的な許可がない限り使わない方針とした。

**smartlabo-works / smartlabo-works-lite の両リポジトリとも、読み取りのみで一切変更していない。**

## 4. UI改善（WEB-V2-1からの変更点と理由）

| 項目 | 変更 | 理由 |
|---|---|---|
| ヘッダーの明暗 | Navy → 白（半透明＋blur） | 法人向けの信頼感・高級感は、濃色より余白の効いた明色のほうが出る。Stripe / Notion / Linear と同系統の判断 |
| ヘッダー高さ | 72px → 64px | 「高さは小さめ」の指示 |
| **ロゴの組み方** | ロックアップ画像 → **アイコンマーク（正式アセット）＋文字** | 下記参照 |
| ナビ折り返し | 860px → 1080px | 日本語6項目＋CTAが860pxで1行に収まらないため |
| `--text-secondary` | `#64748B` → `#5C6B82` | コントラストAA未達の解消（下記参照） |

### ロゴの扱いについて（要確認）

`logo-primary.png` / `logo-white.png` は **アイコン＋「Smart Labo」＋「Works」＋タグライン「会社を動かすAI。」の3階層ロックアップ**（531×180）で、ヘッダーの32〜40pxでは文字が完全に潰れて判読できなかった（初回実装で確認済み）。

そのため、ヘッダーとフッターでは **`icon-color` / `icon-white`（正式アセットのアイコンマーク単体）＋ HTMLテキストの「Smart Labo Works」** で組んだ。

- `DESIGN_ASSETS/01_LOGO/README.md` が用途別に `Icon/` を用意していること、実際のプロダクトUI（ライト版サイドバー）も同じ組み方であることに従った判断です。
- **ロゴの再生成・トレース・色変更・加工・回転・縦横比変更は一切していません。** 高さのみ指定・幅 `auto` を維持し、縦横比の保持をブラウザ実測で確認済み。
- 大きく置ける場所（今後のCTA・会社紹介など）ではロックアップを使う方針です。
- ロックアップをヘッダーにも使いたい場合は、ヘッダー高さを80px以上へ広げる必要があります。ご指示があれば変更します。
