**「お問い合わせページの実装」**

残る骨格ページは `contact.html` のみ。ただし着手には**問い合わせ方式の確定（代表判断）が前提**となる。

GitHub Pages は静的ホスティングのため PHP を実行できず、v1 の `xserver-form/` をそのまま使うことはできない。次のいずれかを選ぶ必要がある。

1. 外部フォームサービスを利用する
2. Xserver 等に置いた `contact.php` へクロスオリジンで送信する
3. v1と同様、当面は `mailto:` のみとする

**方式が決まるまでは、フォームUIを実装しない**方針をv2で維持している。方式が決まらない場合は、先に **WEB-V2-7「全ページ通しの最終レビュー」**（表記ゆれ・リンク網羅・OGP・sitemap の最終確認）へ進むことを推奨する。
