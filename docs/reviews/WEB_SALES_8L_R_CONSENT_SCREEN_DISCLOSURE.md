## 1. 代表方針（本工程で正式採用した方式）

公開Websiteへ Lite の法務本文・所在地・電話番号を広く掲載しない。
**Lite の有料契約前の最終確認画面で法務文書を閲覧し、明示同意した場合にのみ決済へ進む**方式を正式採用する。

具体的には次のとおり。

1. Lite法務3文書の正本は、引き続き `server/services/legal/legalDocuments.js` の1か所だけ。
2. 利用規約・プライバシーポリシー・特定商取引法に基づく表記は、
   **Lite の有料契約前の最終確認画面**からクリックして読める。
3. 3つの同意チェックがすべて入らなければ Checkout Session を作成できない仕組みを維持する。
4. 法務ページは、ログイン不要／URLを知っていれば閲覧可能／`meta robots=noindex`／
   `X-Robots-Tag: noindex`／契約後も設定画面から再確認可能。
5. 所在地・電話番号・受付時間は、Lite の「特定商取引法に基づく表記」の中で表示する。
6. 公開Websiteの会社紹介ページ・料金ページ・通常フッターへは掲載しない。
7. 公開Website上に Lite 特商法本文を複製しない（正本を二重管理しない）。

## 2. 公開WebsiteとLite契約文書の役割分離

| 適用対象 | ホームページ本体と**お問い合わせフォーム**の利用条件・個人情報の取扱い | **有料契約そのもの**（契約期間・料金・解約・返金・データの取扱い） |

両者は別文書であり、同じものとして扱わない。Website側の本文にも

## 3. 所在地・電話番号を一般会社ページへ掲載しない理由

- これらは**販売条件の表示として必要な情報**であり、必要な場面は「有料契約の申込み直前」である。
  その場面では Lite の特定商取引法に基づく表記に必ず表示され、同意の対象にもなる。
- 一般の会社紹介ページ・フッターへ広く掲載すると、契約と無関係な閲覧者に対しても
  代表個人の連絡先が常時公開される状態になる。代表判断により、掲載範囲を
  「契約前確認画面」へ絞る方式を採用した。
- 掲載場所を1か所（Lite側の正本）に限ることで、内容の二重管理と食い違いも避けられる。

## 4. 契約前・契約後に確認できること（実測で確認）

- **契約前**：`payment_required` の会社管理者が最終確認画面を開き、
  利用規約・プライバシーポリシー・特定商取引法に基づく表記を**別タブで**開いて全文を読める。
  別タブで開いても同意チェックの状態は失われない。
- **明示同意後だけ決済へ進む**：3項目すべてにチェックが入るまで申込ボタンは押せない。
  画面を回避してAPIを直接呼んでも、サーバー側が同意記録を確かめて 409 で止め、
  **Stripe を1回も呼ばない（Checkout Session 0件）**。
- **noindexだがURLで閲覧可能**：`/legal/terms` などはログイン不要で開ける。
  同時に `meta robots=noindex, follow` と `X-Robots-Tag: noindex, follow` を返し、
  検索結果には出さない。申込前に必ず読める状態と、検索露出をしない状態を両立させる。
- **契約後も再確認可能**：設定画面の契約カードに「規約・販売条件のご確認」を置き、
  契約状態（active / past_due / canceled / payment_required）によらず3文書を開ける。
  8L までは人数変更ブロックの中にあり `active` のときしか出なかったため、
  契約カード直下へ移した（**本文は複製せず、正本へのリンクのみ**）。
- **特商法表記の内容**：株式会社スマートラボ／代表取締役　小川 昌利／
  鳥取県八頭郡八頭町下濃276番地2／090-4650-7417／平日9:00〜17:00（土日祝日・当社休業日を除く）
  が表示されることを実測で確認。
