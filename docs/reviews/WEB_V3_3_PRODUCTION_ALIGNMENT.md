## 16. スクリーンショットについての判断

本工程では**追加しない**。理由：Company Brain・ダッシュボードの画面を載せるには
完全架空データでの再撮影が必要で、既存4枚（顧客・記録・タスク・文章作成）と
撮影条件・UIバージョンを揃えないと品質が下がる。
改善案：WEB-V3-4等で「架空データの本番同等環境で /brain と /dashboard を撮影して差し替える」
工程を分けるのが安全。
