## 1. 3つのSSOTの役割分担（最重要）

このカンプは **デザインの SSOT であって、掲載内容の SSOT ではない。**

| SSOT | 実体 | 決めること |
|---|---|---|
| **DESIGN SSOT** | 本カンプ | レイアウト・情報密度・人物サイズ・写真と漫画の使い分け・UI画面の見せ方・色面・セクション間のつながり・視線誘導・料金表の見せ方・CTA配置 |
| **PRODUCT / SALES / PRICE SSOT** | `smartlabo-salon` の営業SSOT・価格SSOT、HP制作価格SSOT | 掲載してよい機能・価格・契約条件・禁止表現 |
| **IMPLEMENTATION RULE** | `.claude/skills/salon-web-design/` | 実装方法・namespace・A11y・画像最適化・確認手順 |

**カンプに描かれていても、正式仕様に存在しない機能・効果表現はそのまま掲載しない。**
構造だけを継承し、内容は正式SSOTへ置換する。

## 2. 現行HTMLとの優先順位

```

```

再構築では **「現在の salon.html をなるべく残す」ことを優先しない。**

## 3. カンプから継承するもの（DESIGN SSOT）

### A. ページ全体
- 1枚の営業資料のような一体感
- 情報密度が高い。無意味な巨大余白を作らない
- スクロールするたびに内容が見える
- セクション同士が孤立しない
- 暖色の Salon 世界観をページ全体で維持
- **地色は白／アイボリー／淡ピンク／ベージュの明るい世界に収める。**
  暗色の面をページのどこにも作らない（最終CTAも含む）

### A-2. セクション順序（REBUILD-2 代表判断で確定・DESIGN SSOT）

**カンプの順序を、Phase 2 で承認した旧順序より優先する。**

```
HERO
  → 機能ナビ帯              #features
  → できること／実画面      #screens
  → 導入メリット            #benefits
  → 補足（攻める集客・お悩み漫画・ホームページ）
                            #revisit → #manga → #website
  → 料金                    #pricing
  → 導入フロー              #flow
  → FAQ                     #faq
  → 最終CTA                 #cta
```

- **`#benefits` を `#screens` より前に戻さない。**
  カンプは「何ができるか（実画面）」を先に見せ、そのあとに「導入すると変わる」を置く
- 料金のあとに補足セクションを挟まない。料金 → フロー → FAQ → CTA で終える
- **section id は順序を変えても維持する**（外部共有済みアンカー）
- ヘッダーナビの並びは、ページの出現順に合わせる

### B. HERO
- 人物写真を大きく使う／左に商品説明・右に人物
- CTA や補足は HTML で配置
- ファーストビューで何の商品か理解できる
- **Phase 4B の HERO は既に正式承認済み。カンプを理由に無断で作り直さない。**

### C. 機能ナビゲーション
- HERO 直下に主要機能を短く一覧表示（カンプは白帯に横一列7項目）
- **カンプに存在する未提供機能はそのまま掲載しない**（§5 の変換表に従う）

### D. 実画面
- 実際の Salon 画面を**大きく**見せる。小さなカードへ閉じ込めない
- 「何ができるか」と「実際にどう見えるか」を同時に理解できる構成
- カンプは 左=番号付き説明 / 右=実画面グリッド の非対称構成。これを継承する

### E. 漫画
- 漫画はアクセントではなく**営業説明の主要手段**
- ただし全セクションを漫画にしない。リズムを作る：

```
写真 → UI → 漫画 → UI → 漫画 → 料金
```

### F. 料金
- **HTML。価格を画像へ焼き込まない**
- カンプのように比較しやすくコンパクトに3カラム
- HP制作はオレンジ系で「別商品」と見た目で分かる

### G. CTA
- ページ末尾だけでなく、購入検討が高まる位置へ適切に配置
- ただし**乱立させない**

**最終CTA の地色（REBUILD-2 代表判断で確定・DESIGN SSOT）**

- **暖色ダークは廃止した。二度と戻さない。**
  `--sa-bg-deep` `--sa-on-deep` `--sa-on-deep-2` `.btn--on-inverse` は削除済み
- 使う色は **淡いピンク／白／Salon Pink**（必要ならオレンジをアクセントに）
- カンプ下部の「まずは相談してみよう」という**軽さ**を再現する。
  重い・締める・引き締めるための暗色面を作らない
- カンプ下部にある **QRコード／LINE相談／メールアドレス直書きは追加しない**（代表判断）。
  正式な問い合わせフォームへのCTAを主役にする
- 主CTAの文言は「まずは無料で相談してみる」。副CTAは資料請求
- 主CTAの周囲に「何を相談できるか」の安心材料を短いHTMLテキストで置いてよい
  （導入について相談／自分のサロンに合うか相談／料金や機能について相談）。
  **ここに新しい未提供機能・実績・効果保証を書かない**
- CTA → アウトロ帯 → フッターは、地色を段階的につないで切れ目を作らない

## 4. カンプからコピー禁止（PRODUCT SSOT 未確認のまま実装しない）

**架空の数値・実績**
- 売上金額・新規顧客数・リピート率などの実績風の数字
- 「導入事例」ナビ項目

## 6. カンプをそのまま画像として貼らない

このカンプは **1枚画像としてページに掲載するためのものではない。**
HTML / CSS / 正式画像素材 / 実際の Salon UI / リンク / CTA へ**再構築する**ための見本である。

- カンプを縮小して貼り、文字を読ませる実装にしない
- カンプ内の文字（見出し・機能名・価格・説明）は **HTML テキストで持つ**
- カンプ内の人物・漫画・情景だけを**正式素材として切り出す／作り直す**
